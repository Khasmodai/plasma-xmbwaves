# XMB Waves — KDE Plasma 6 Wallpaper Plugin

> **Disclaimer:** This project was generated by **Gemini 4 Argon**.

![XMB Waves — Celestial Silk (Default Preset)](preview.png)

**XMB Waves** (`org.kde.plasma.xmbwaves`) is a native, hardware-accelerated animated wallpaper plugin for **KDE Plasma 6.x** inspired by the classic Sony PSP / PlayStation 3 XrossMediaBar (XMB) silk ribbon background.

Unlike video loops or web-based wallpapers, **XMB Waves** renders mathematically smooth quadratic-Bézier wave ribbons directly on the GPU in a **single fullscreen fragment shader pass** (`.qsb`), delivering crisp sub-pixel curves at any resolution or ultrawide aspect ratio with near-zero CPU and GPU overhead.

---

## Features

### 1. Single-Pass Native GPU Rendering
- **Analytical Wave Ribbons**: Evaluates the 135° 3-stop background gradient, 4 layered quadratic-Bézier wave ribbons, 3-stop vertical silk gradients per ribbon, and sub-pixel anti-aliased `2px` white crest highlights in a single fragment shader pass (`shaders/xmb.frag`).
- **Resolution & Aspect-Ratio Independent**: Wave amplitudes and vertical proportions scale strictly by viewport height, preventing stretched or squashed ribbons on ultrawide (`21:9`, `32:9`), multi-monitor, or portrait setups.
- **Pre-Compiled Qt 6 RHI Shaders**: Bundled with `.qsb` shaders supporting Vulkan, OpenGL, and other Qt 6 RHI backends out of the box.

### 2. Performance & Power Efficiency
- **Frame Rate Limiter**:
  - **VSync** (Native monitor refresh rate)
  - **60 FPS**
  - **30 FPS** *(Recommended for power saving)*
  - **24 FPS** *(Cinematic)*
  - **15 FPS** *(Ultra low power)*
  - **Static / Paused** *(0% GPU)*
- **Zero Idle Wakeups & DPMS Awareness**: When capped or when your monitor enters power-saving sleep (DPMS off) on the desktop or lock screen, the frame clock halts completely (**0 FPS / 0 timer wakeups / 0% CPU & GPU**), resuming seamlessly from the exact wave phase when the screen wakes.
- **Smart Pause**: Automatically pauses rendering on the desktop whenever a maximized or fullscreen window covers that monitor, while remaining independent on the KDE Lock Screen.
- **Animation Speed Multiplier**: Adjustable from `0.10x` to `3.00x` (`1.00x` default) without phase jumps.
- **Plasma Accent Color Integration**: Exposes the active primary wave color to Plasma's *"Accent color from wallpaper"* system setting.

### 3. Three Color Modes
1. **Preset**:
   - Choose from 9 curated palettes:
     - *Celestial Silk (Light)* — Default airy silver-blue & periwinkle silk
     - *PS3 Midnight Sapphire (Dark)*
     - *Emerald Breeze (Light)*
     - *Emerald Depths (Dark)*
     - *Amethyst Dusk (Dark)*
     - *Sakura Mist (Light)*
     - *Sunset Amber (Dark)*
     - *Crimson Silk (Dark)*
     - *Monochrome Silver (Dark)*
2. **Harmonized**:
   - Pick a single base color and choose a harmony style (*Soft Silk (Light)*, *Deep XMB (Midnight Dark)*, or *Rich Dusk (Twilight)*) to automatically generate a cohesive analogous palette across the 3-stop background gradient and all 4 wave ribbons.
3. **Custom**:
   - Full manual control over all 3 background gradient stops (*Start*, *Middle*, *End*) and each of the 4 wave ribbons (*Wave 1*–*Wave 4*), with one-click buttons to seed custom colors from the active **Preset** or **Harmonized** palette.

## Requirements

- **KDE Plasma 6.0+** (`plasmashell` / `kpackagetool6`)
- **Qt 6** (`QtQuick`, `Kirigami`, `KQuickControls`)
- *(Optional, for rebuilding shaders from source)* `qt6-shadertools` (`qsb-qt6` or `qsb`) — precompiled `.qsb` shader packages are already included in `package/contents/ui/shaders/`.

## Installation

Clone the repository and run the installer script:

```bash
git clone https://github.com/Khasmodai/plasma-xmbwaves.git
cd plasma-xmbwaves
./install.sh
```

What `install.sh` does:
1. Recompiles `shaders/xmb.vert` and `shaders/xmb.frag` into Qt 6 `.qsb` shader bundles if `qsb-qt6` / `qsb` is installed (otherwise uses the precompiled bundles).
2. Installs (or upgrades) the wallpaper package into `~/.local/share/plasma/wallpapers/org.kde.plasma.xmbwaves/` via `kpackagetool6`.
3. Prompts (`[y/N]`) whether you want to clear `plasmashell`'s QML cache and restart `plasmashell` (useful when upgrading an already-loaded version).

### Activating the Wallpaper

- **Desktop Wallpaper**:
  1. Right-click anywhere on your desktop and select **Desktop and Wallpaper** (or **Configure Desktop and Wallpaper...**).
  2. Set **Wallpaper type** to **XMB Waves**.
- **Lock Screen Wallpaper**:
  1. Open **System Settings** → **Screen Locking** → **Configure Appearance...**
  2. Set **Wallpaper type** to **XMB Waves**.

## Uninstallation

```bash
make uninstall
# or directly via kpackagetool6:
kpackagetool6 --type Plasma/Wallpaper --remove org.kde.plasma.xmbwaves
```
